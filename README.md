# How to test your MCP Server


## Pre-requesites
1. Install the mcp-inspector package globally.

Install nodemon.

Check that package.json has a "dev" script:

`"dev": "nodemon --watch src --exec tsx src/index.ts"`

This allows you to run `npm run dev`.


2. Open a command line and run:
`mcp-inspector npm run dev`
