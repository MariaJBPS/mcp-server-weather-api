# How to Test Your MCP Server

## Prerequisites

Before getting started, make sure you have the following installed:

### 1. Install required packages

Install **mcp-inspector** globally:

```bash
npm install -g mcp-inspector
```

Install **nodemon** (if not already installed):

```bash
npm install -g nodemon
```

---

### 2. Verify your project setup

Ensure your `package.json` includes a `dev` script like this (where src/index.ts is the entry point):

```json
"scripts": {
  "dev": "nodemon --watch src --exec tsx src/index.ts"
}
```

This allows you to run your server in development mode with:

```bash
npm run dev
```

---

## Running the MCP Server with Inspector

Start your MCP server using **mcp-inspector**:

```bash
mcp-inspector npm run dev
```

This will:

* Launch your server using the `dev` script
* Attach the MCP Inspector for debugging and testing
